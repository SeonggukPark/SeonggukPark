## **6-2. README 파일 (with Markdown)**
- 방문자에게 repository 설명 위한 파일
- 기본적으로 markdown 문법 사용

### markdown 기본 문법
**제목 입력**
```plain text
# 제목 1
## 제목 2
### 제목 3
#### 제목 4
##### 제목 5
###### 제목 6
```

**가로줄 입력**
```plain text
--- or ***
```

**강조**
```plain text
*기울임* 또는 _기울임_
**굵게** 또는 __굵게__
~~취소선~~
```

**목록**
```plain text
- 항목 1
  - 하위 항목
    - 하위 하위 항목
1. 첫째
2. 둘째
```

**코드**
' \` ' (backtick) 3개로 열고 닫기
