# (1) 모던 환경이란?
### 모바일 디바이스
- 대다수의 스마트폰, 태블릿이 리눅스의 변형인 안드로이드OS 탑재
### 클라우드 컴퓨팅
- 클라우드 제공업체로의 대규모 아웃소싱 확립
### 사물인터넷
- IoT 환경에서 리눅스를 시작하고 싶다면, AWS IoT Edukit 참고
### 프로세서 아키텍쳐의 다양성
- 인텔은 여전히 데스크톱과 노트북에서 많이 이용되지만, 모바일 디바이스의 등장으로 ARM 아키텍처가 도입되었으며 최근에는 RISC-V의 사용도 늘어나는 중
- 동시 Go, Rust 같은 다중 아키텍처 프로그래밍 언어 및 도구가 널리 보급되는 중

# (2) (지금까지의) 리눅스 이야기
### 1990년대
- 최초 상용 제품인 레드햇 리눅스 등장
### 2000\~2010년
- 구글, 아마존, IBM 같은 거대 기업이 도입 추진하며 엄청난 성장세를 보임
### 2010년 이후
- 데이터 센터, 클라우드, 모든 IoT 디바이스, 스마트폰에서 중추적 역할
- 대부분 상용 시스템은 레드헷 or 데비안 기반

# (3) 운영체제는 왜 필요한가
- OS가 없다면 메모리 관리, 인터럽트 처리, I/O 디바이스 통신, 파일 관리, 네트워크 스택 구성 및 관리 등 거의 모든 작업을 직접 처리해야 함
→ OS는 이러한 무거운 작업을 수행해 하드웨어 요소를 추상화
→ 리눅스 커널같은 API도 제공
→ OS가 제공하는 API를 시스템 콜(System call), 줄여서 시스콜(sys call)이라 함
→ 러스트, 파이썬, 자바 같은 고급 프로그래밍 언어는 이러한 시스템 콜 위에서 빌드 됨
# (4) 리눅스 배포판
- (리눅스) 커널 : 시스템 콜 + 디바이스 드라이버
- 리눅스 배포판 : 커널과 관련 구성 요소의 전체 번들 (패키지 관리, 파일 시스템 layout 등 포함)
- 기존 배포판: 우분투, 레드헷
- 모던 배포판: 보틀로켓, 플랫카

# (5) 리소스 가시성
- 리눅스는 기본적으로 리소스의 전역 보기(global view)를 지원
- 리소스 : 소프트웨어 실행을 지원하는 데 사용할 수 있는 모든 것 
- e.g.) HW 및 그 추상화, 파일시스템, HDD, SDD, 프로세스, 네트워킹 관련 항목, 자격증명
