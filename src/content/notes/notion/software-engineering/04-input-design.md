## 4-1. 입력 설계의 개요

[Notion 원본](https://app.notion.com/p/33f6b9674ad880f193f7e30ea157596c)

- 입력 설계: 사용자에게 요구되는 다양한 정보중 입력할 정보를 선택
![4-1. 입력 설계의 개요 이미지](/SeonggukPark/images/notion/notes/software-engineering/04-01-1.png)

### (1) 입력 설계의 표준화
#### \[1\] 형식의 표준화
#### \[2\] 등록의 표준화
#### \[3\] 폼 디자인의 표준화
#### \[4\] 매체의 표준화
#### \[5\] 코드의 표준화

### (2) 입력 자료의 발생 설계
##### \[1\] 입력 자료의 명칭
##### \[2\] 작성 목적
##### \[3\] 입력 자료의 발생 장소
##### \[4\] 입력 자료의 발생 방법 및 형태
##### \[5\] 입력 자료의 발생 주기, 시기
##### \[6\] 입력 자료의 발생 건수
##### \[7\] 입력 자료의 오류 체크

### (3) 입력 자료의 수집 설계
##### \[1\] 수집자, 수집 장소
##### \[2\] 수집 방법과 형태
##### \[3\] 수집 경로
##### \[4\] 수집 시기
##### \[5\] 입력 정보의 수집 오류 체크

### (4) 입력 자료의 매체화 설계
- 정보 처리에 입력 정보를 입력이 가능한 매체로 변환하는 것
##### \[1\] 입력 형태의 선택
##### \[2\] 입력매체, 입력 장치의 선택
- 검토 요인
- 시간적 용친
- 입력 정보의 양 혹은 입력 형식
- 비용
##### \[3\] 매체화의 기기
##### \[4\] 매체화 담당자
##### \[5\] 매체화의 장소
##### \[6\] 문자수/건
##### \[7\] 고정 길이(장), 가변 길이(장) 구분
##### \[8\] 매체화 주기 및 시기
##### \[9\] 매체화의 정확성 체크
- 하드웨어에 의한 체크 (e.g. 패리티 체크)
- 사람의 의한 체크 (e.g. 시각에 의한 체크)
- 소프트웨어에 의한 체크 (e.g. 프로그램에 의한 체크 - 숫자, 범위, 논리 등)

### (5) 입력 자료의 투입 설계
- 입력 매체화된 정보를 정보처리 시스템에 입력 하는 것
##### \[1\] 입력 장치
##### \[2\] 투입 주기 및 시기
##### \[3\] 입력 정보의 정확성 점검

### (6) 입력 자료의 내용 설계
- 입력 자료의 목적 달성을 위한 입력 내용 설계
- **원시 전표 설계 단계**라고도 함
##### \[1\] 입력 항목명
##### \[2\] 입력 항목의 배열
##### \[3\] 입력 항목의 자릿수
##### \[4\] 입력 항목의 문자 구분
##### \[5\] 입력 정보 체크

## 4-2. 원시전표의 설계

[Notion 원본](https://app.notion.com/p/33f6b9674ad88045b9baccc0a97eef15)

- 원시전표 : 시스템에 투입되는 최초 자료

##### \[1\] 업무상의 제약
##### \[2\] 현장에서의 제약
##### \[3\] 전표 관리상의 제약
##### \[4\] 하드웨어상의 제약

### (2) 원시전표 작성 설계 원칙
#### 1) 입력량을 적게 한다
![4-2. 원시전표의 설계 이미지](/SeonggukPark/images/notion/notes/software-engineering/04-02-1.png)
#### 2) 일정한 순서에 따라 입력되도록 한다

- 입력 과정에서 혼란 방지 위한 요령을 인쇄하여 부착
- 입력요령, 입력항목은 번호나 기호와 대응
#### 4) 선(line), 상자(boxes), 표제(caption)를 적절하게 지정

##### \[3\] 관리 용이하게
##### \[4\] 파일링 위한 배치도 고려

##### \[3\] 전표상 입력란 표시
##### \[4\] 자리수 길면 점선으로 구분
##### \[5\] 숫자는 숫자, 문자는 문자끼리 모아서 배치
##### \[6\] 항목 명칭 통일

## 4-3. 입력 매체의 설계

[Notion 원본](https://app.notion.com/p/33f6b9674ad880d9a12feeaf8227ee07)

![4-3. 입력 매체의 설계 이미지](/SeonggukPark/images/notion/notes/software-engineering/04-03-1.png)
#### 1) 키보드 입력 방식
#### 2) 문자 입력 방식
##### MICR (Magnetic Ink Character Reader) 방식
- 은행에서 수표 아래쪽에 특수 자기 잉크로 특수 형상에 따른 문자로 인쇄된 것을 읽음
##### OCR (Optical Character Reader) 방식
- 특별한 형상의 문자를 읽는 방식
- 공공요금 통지서 등
- 주로 0\~9까지 문자 인식하는 경우에 주로 사용
#### 3) 마크 입력 방식
- 보통 OMR(Optical Mark Recognizer)라고 하며, 마크 시트와 마크 카드로 구분

![4-3. 입력 매체의 설계 이미지](/SeonggukPark/images/notion/notes/software-engineering/04-03-2.png)

![4-3. 입력 매체의 설계 이미지](/SeonggukPark/images/notion/notes/software-engineering/04-03-3.png)

#### 4) 키보드로부터 자기테이프나 자기디스크에 입력 방식
- 키 투 테이프(key-to-tape) 방식
- 데이터를 **키보드로 입력하여 자기테이프(Magnetic Tape)에 먼저 저장한 후**, 이후 컴퓨터에 일괄 입력하는 **오프라인 입력 방식**
![4-3. 입력 매체의 설계 이미지](/SeonggukPark/images/notion/notes/software-engineering/04-03-4.png)

#### 5) 기타 입력 방식
##### (1) 음성 방식
##### (2) 포인팅 입력 장치
- 마우스, 트랙볼, 조이스틱 등
##### (3) 터치 스크린
##### (4) 기록과 그림 입력 장치
- 라이트팬, 스타일러스, 디이타이저, 스캐너

## 4-4. 입력 형태의 종류

[Notion 원본](https://app.notion.com/p/33f6b9674ad880dabf9ef30f0e4aec9d)

### (1) 온라인 입력 방식
- 입력 장치(단말기)가 **컴퓨터와 직접 연결된 상태에서 데이터를 입력과 동시에 처리하는 방식**
#### 1) 디스플레이 방식
##### 특성
- man-machine interface (사람-컴퓨터 간 대화 기능)
- 조작 용이
- 잘못 취급 시 보호 조치 가능
#### 2) 키보드 프린터 방식
- 키보드 입력 자료가 컴퓨터 처리 후 출력되는 프린터 방식
#### 3) 데이터 수집 방식
- 원거리에 떨어진 단말기로부터 입력된 자료를 시스템에서 바로 처리

### (2) 오프라인 입력 방식
- 입력 자료를 먼저 보조기억장치(테이프·디스크 등)에 저장한 후 컴퓨터에 일괄 처리하는 방식
#### 1) 집중 입력 방식
![4-4. 입력 형태의 종류 이미지](/SeonggukPark/images/notion/notes/software-engineering/04-04-1.png)
#### 2) 분산 입력 방식
- 집중 입력과 달리 매체화의 장소가 입력 현장
![4-4. 입력 형태의 종류 이미지](/SeonggukPark/images/notion/notes/software-engineering/04-04-2.png)
#### 3) 직접 입력 방식
- 원시 전표를 거치지 않고 입력 정보를 바로 기록
- OMR, 마크카드, 마크시트 등 이용
![4-4. 입력 형태의 종류 이미지](/SeonggukPark/images/notion/notes/software-engineering/04-04-3.png)
#### 4) 변환 입력 방식
- 컴퓨터에서 출력된 정보를 그 형태 그대로 다시 입력 정보로 사용
![4-4. 입력 형태의 종류 이미지](/SeonggukPark/images/notion/notes/software-engineering/04-04-4.png)

#### 5) 턴 어라운드 시스템
- 사용자가 입력한 작업 **일괄 처리**방식으로 처리하고, 일정 시간이 지난 후 **처리 결과를 다시 사용자에게 반환하는 시스템**
- 대화형 시스템(Interactive System)이 아님<br><br>

## 4-6. 입력 데이터 체크

[Notion 원본](https://app.notion.com/p/33f6b9674ad88056b4f6fd4da4dcfac7)

- 오류 데이터를 이용하기 전에 수정함으로써 정확한 데이터 처리가 되도록 한다 
#### 1) 입력 데이터 체크 방식
##### \[1\] 사람 체크
##### \[2\] 검공 체크
##### \[3\] 하드웨어에 의한 체크
- 마크가 정상적으로 표시되어 있는지를 검사
- parity check 방법
##### \[4\] 소프트웨어에 의한 체크
- 프로세스 설계시 반영

#### 2) 오류 데이터의 처리 시점
##### \[1\] 피드백 방식
- 에러 리스트 작성 후 원시전표 발행 부서에 반송
##### \[2\] 자동 정정 방식
- 특정 규칙에 따라 에러 데이터를 대체 혹은 정정하여 다시 입력
##### \[3\] 에러 데이터 제거 방식
- 한번에 처리하지 않거나 일부 데이터를 버리고 처리해도 결과에 영항을 미치지 않을 경우, 에러 데이터를 제거하고 정상 데이터만으로 처리
