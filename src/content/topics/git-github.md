## 학습 목차

1. **Git 시작하기** — 버전 관리·백업·협업의 역할과 CLI 환경
2. **Git으로 버전 관리하기** — 작업 트리, 스테이지, 커밋과 이력 복구
3. **브랜치와 병합** — 분기, 충돌 해결, cherry-pick과 병합 전략
4. **GitHub 시작하기** — 원격 저장소, push·pull, SSH 인증
5. **GitHub로 협업하기** — clone, fetch, Pull Request와 코드 리뷰
6. **GitHub에서 소통하기** — 프로필, README와 Markdown

## 공개 방향

명령어 사전 형태로 옮기기보다 실제 저장소에서 자주 마주치는 충돌 해결, 안전한 이력 복구, 협업 브랜치 운영을 중심으로 글을 정리합니다.
