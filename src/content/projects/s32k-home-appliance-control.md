## 프로젝트 개요

마이크로프로세서설계실험 과목에서 수행한 통합 가전 제어 시스템 개발 프로젝트입니다. 센서 입력을 바탕으로 여러 가전을 제어하는 알고리즘을 설계하고, 이를 상용 MCU인 S32K 보드에서 동작하는 펌웨어로 구현하는 것을 목표로 했습니다.

팀장으로서 프로젝트를 S/W와 H/W 영역으로 나누어 역할과 일정을 관리했으며, 펌웨어 개발과 최종 H/W-S/W 통합을 담당했습니다.

## 담당 역할

- 팀장으로서 S/W·H/W 업무 분담, 개발 일정과 통합 과정 관리
- 센서 입력에 따른 가전 제어 알고리즘 설계
- S32K 보드용 C 기반 펌웨어 개발
- 인터럽트와 ADC, 입출력 신호를 사용하기 위한 레지스터 설정
- 작성 코드와 회로를 연동한 통합 테스트 및 문제 분석

## 구현 과정

S32K는 교육용 보드와 달리 프로젝트에서 바로 활용할 수 있는 고수준 API가 제한적이었습니다. 인터럽트와 주변장치를 사용하고 원하는 입출력 신호를 생성하기 위해 데이터시트를 확인하며 비트 단위로 레지스터 값을 설정했습니다.

센서 입력을 ADC로 변환하고, 변환 결과에 따라 모터를 포함한 가전 장치를 제어하도록 전체 흐름을 구성했습니다. 각 팀원이 작성한 모듈을 하나의 펌웨어로 통합한 뒤 실제 회로와 연결해 동작을 검증했습니다.

## 모터 구동 문제 해결

프로젝트 마감을 일주일도 남기지 않은 시점에 수천 줄의 코드와 회로를 통합했지만 모터가 동작하지 않는 문제가 발생했습니다. 코드 리뷰에서 문법적 오류를 발견하지 못해 보드를 교체했으나 같은 현상이 반복됐고, 하드웨어 자체가 원인이 아니라는 점을 확인했습니다.

팀원들과 MCU 데이터시트의 설정값과 코드의 레지스터 값을 모듈별로 대조했습니다. 주변장치 초기화 흐름을 밤새 추적한 끝에 ADC 모듈의 레지스터 값 하나가 잘못 설정되어 센서 입력이 의도대로 전달되지 않는 것을 발견했습니다. 해당 값을 수정한 뒤 다시 통합 테스트를 수행했고, 모터가 정상적으로 구동되는 것을 확인했습니다.

## 결과와 배운 점

- 센서 입력부터 가전 제어까지 이어지는 S32K 기반 임베디드 시스템을 완성했습니다.
- 레지스터 수준에서 주변장치의 동작을 추적하며 데이터시트 기반 디버깅 경험을 쌓았습니다.
- 원인을 특정하기 전 부품을 포기하기보다 팀원들과 설정값을 체계적으로 검증해 프로젝트를 일정 내 마무리했습니다.
- H/W와 S/W가 결합된 문제일수록 영역을 나누기보다 공동으로 관찰 결과를 공유하는 협업이 중요하다는 점을 배웠습니다.
