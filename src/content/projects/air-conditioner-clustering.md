## 프로젝트 개요

LG전자 산학과제로 수행한 시스템 에어컨 협조 제어용 실내기 분류 모델 개발 프로젝트입니다. 별도의 위치 정보 없이 센서 시계열 데이터로 동일 공간에 설치된 실내기를 분류하는 것을 목표로 했습니다.

## 담당 역할

- 온도와 습도 시계열 데이터를 요약하는 벡터 기반 Clustering 모델 개발
- Python 모델을 C++로 변환
- 실외기 내부 Embedded Linux 추론 엔진에 모델 이식

## 핵심 구현

실내기별 센서 변화 패턴을 벡터로 표현하고 Cosine Similarity를 이용해 데이터의 방향성이 유사한 실내기를 같은 공간으로 분류했습니다.

모델 정확도만 확인하는 데 그치지 않고 실제 제품 환경에서 실행할 수 있도록 C++로 전환하고 기존 추론 엔진과 통합했습니다.

## 결과

- 실제 현장 기준 약 90% 수준의 분류 정확도를 달성했습니다.
- 개발 모델의 C++ 전환과 Embedded Linux 환경 이식을 완료했습니다.
