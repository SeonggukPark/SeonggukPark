## Seongguk Park

안녕하세요. 박성국입니다.

본 계정은 학부시절 주로 알고리즘 학습을 위해 사용되었으며,

최근에는 Linux, Android Study 및 AI를 활용한 Side Project 기록용으로 활용하고 있습니다.

### Portfolio

- [포트폴리오 웹사이트](https://seonggukpark.github.io/SeonggukPark/)
- [포트폴리오 소스 코드](https://github.com/SeonggukPark/SeonggukPark)

### Portfolio Development

Astro와 Markdown Content Collections를 사용한 포트폴리오 겸 기술 블로그입니다.

```bash
npm install
npm run dev
```

- 프로젝트: `src/content/projects`
- 기술 글: `src/content/posts`
- 학습 노트: `src/content/notes`
- 경력과 기술 스택: `src/data/site.ts`
- 작성 형식: [`CONTENT_GUIDE.md`](./CONTENT_GUIDE.md)

`main` 브랜치에 반영된 변경은 GitHub Actions를 통해 GitHub Pages로 배포됩니다.
