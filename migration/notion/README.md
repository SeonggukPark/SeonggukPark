## 사이트에 옮길 때 사용할 형식

모든 후보는 다음 필드를 기준으로 관리한다.

```text
target       project | post | note | resume
status       바로 반영 | 재작성 | 확인 필요 | 보관 | 제외
slug         사이트에서 사용할 영문 식별자
title        공개 제목
summary      목록에 표시할 1~2문장
tags         검색과 분류에 사용할 기술 태그
source       ZIP과 Notion 문서 제목
evidence     결과를 뒷받침하는 수치·코드·발표 자료
checks       공개 전 검증하거나 보완할 사항
```

기술 글은 `배경 → 문제/제약 → 선택한 접근 → 구현/실험 → 결과 → 배운 점` 순서로 재구성한다. 알고리즘 글은 문제 지문을 옮기지 않고 `핵심 모델링 → 자료구조 선택 → 복잡도 → 실패한 접근 → 검증 코드`만 개인 언어로 작성한다.

## 원본 보존 원칙

세 ZIP은 수정하지 않는다. 이미지·PDF·PPTX·HWP는 필요한 항목만 `public` 또는 별도 다운로드 디렉터리로 복사하고, 출처와 공개 권한을 확인한 뒤 사용한다. HWP 보고서는 현재 환경에서 본문을 안전하게 추출할 수 있는 도구가 없어 내용 반영 대상에서 보류했다.
