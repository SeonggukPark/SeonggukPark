# 알고리즘 기록 정리

`algorithms.zip`은 문제 풀이 코드와 교육 메모가 혼합되어 있다. 190개 Markdown 중 중복 사본 59개를 제외하면 131개가 남는다. 같은 문제의 여러 export 사본은 가장 최신이 아니라 **본문이 완성되고 코드가 다시 통과한 한 개**만 선택한다.

## 게시 형식

알고리즘 글은 문제 지문이나 공식 해설을 복제하지 않고 다음 구조로 다시 작성한다.

```text
문제 링크와 출처
제약에서 도출한 목표 복잡도
상태와 연산을 어떻게 모델링했는가
자료구조를 선택한 이유
실패하거나 시간 초과가 난 접근
검증된 핵심 코드만 발췌
시간·공간 복잡도
경계값 테스트와 다시 풀 날짜
```

사이트 분류는 긴 분석을 `post`, 짧은 패턴과 실수 기록을 `note`로 둔다. 원본 전체 코드는 가능하면 GitHub 저장소에 두고 글에서는 핵심만 보여준다.

## 시뮬레이션 문제 묶음

코드트리/Samsung 유형 문제는 개별 풀이 수십 편을 그대로 공개하기보다 다음 주제의 대표 사례 1~2개만 선정한다.

| 주제 | 대표 원문 후보 | 글에서 다룰 관점 |
| --- | --- | --- |
| 회전 후 탐색 | 고대 문명 유적 탐사, 예술성 | 좌표 변환, 임시 격자, BFS component 계산, tie-breaker |
| 여러 객체 동시 이동 | 메두사와 전사들, 루돌프의 반란 | 턴 순서, 상태 snapshot, 충돌과 우선순위 |
| 복합 공간 표현 | 미지의 공간 탈출 | 서로 다른 면/공간 사이 좌표 전환과 디버깅 |
| 자료구조가 핵심인 시뮬레이션 | 코드트리 DB, 코드트리 등산 게임 | 명령별 복잡도와 인덱스 유지 |

선정 조건은 `현재 코드 재통과`, `본인의 실패 과정 기록`, `복잡도 설명 가능`, `문제 링크 제공` 네 가지다. 조건을 만족하지 않으면 비공개 풀이 저장소에만 둔다.

## 교육·학습 이력으로 활용

`교육`, `예선 챌린지`, `떠먹여주는 알고리즘`의 자료는 독립 글보다 이력서의 학습 활동을 뒷받침하는 근거로 사용한다.

- 시간복잡도, 재귀·정렬, 문자열, DFS 기초 과정
- Trie, Hash, Segment Tree, Union-Find, 최단경로 등 B형 대비 학습
- 멘토링과 해설 특강을 통한 최적화·클린 코드 피드백
- 2025년 스터디 일정은 완료 여부를 다시 확인하고 공개 이력에 포함하지 않는다.

## 오류·미완성으로 확인된 항목

- `이터레이터 무효화`: `std::erase_if` 표준 버전과 호출 형식 오류
- `출근길 라디오`: tree 초기화 구간과 query/update의 인덱스 기준이 혼재
- `전송시간`: 제목에 `다시 풀기`가 명시되어 있고 캐시 갱신 로직 검증 필요
- `파일저장소`와 `조직개편`: 문서 본문 또는 이미지가 서로 복제된 흔적
- `빈출 유형 정리`: 큰 분류는 좋지만 다수 섹션이 제목만 있고 설명이 없음
- 일부 코드 fence에 `cpp`, `코드 복사` 같은 Notion 복사 잔여물이 포함됨

이 항목들은 원문 코드를 그대로 사이트로 복사하지 않는다.
