# 통합 반영 백로그

다음 단계에서 실제 페이지에 반영할 순서다. 한 번에 모든 자료를 옮기지 않고, 포트폴리오 신뢰도를 먼저 높인 뒤 기술 글을 확장한다.

## 2단계: 대표 기술 글 4편

1. `inode에서 VFS까지: Linux 파일시스템을 따라가기`
2. `컨테이너를 이루는 Linux 기능: namespace, cgroup, CoW`
3. `객체 수명과 virtual destructor`
4. `격자 시뮬레이션 구현 체크리스트`

각 글은 원문 요약을 복사하지 않고 직접 재현한 코드·명령·테스트 결과를 포함한다. 이 네 편이면 Embedded/System/C++/Algorithm의 핵심 축을 고르게 보여줄 수 있다.

## 3단계: 실전 노트와 심화 글

- Linux 장애 대응 첫 10분 명령어
- 셸의 스트림과 작업 제어
- 컨테이너별 C++ iterator 무효화 규칙
- 문자열을 실제로 뒤집지 않는 lazy reverse 설계
- Node pool Trie와 wildcard 검색
- 계층형 그래프 최단거리 캐시: 재풀이 통과 후 공개
