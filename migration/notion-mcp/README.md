# Notion MCP 직접 마이그레이션

기준일: 2026-07-24

ZIP export를 거치지 않고 Notion MCP로 조회한 페이지를 이 프로젝트의 콘텐츠 형식으로 옮긴 기록이다. Notion 원본은 변경하지 않았으며, 공개 여부를 검토하지 않은 학습 기록은 모두 비공개 초안으로 유지한다.

## 반영 원칙

- 공개 프로젝트에는 Notion 원문에서 확인되는 설명과 성과만 사용한다.
- 학습 기록은 `src/content/notes/notion`에 `draft: true`로 가져온다.
- 만료되는 Notion 이미지 URL은 `public/images/notion` 아래의 로컬 경로로 교체한다.
- 전화번호, 상세 주소, 자격번호는 공개 콘텐츠에서 제외한다.
- 기존 ZIP 기반 초안 151개는 삭제하지 않고 `migration/zip-export/notes-imported`에 보관한다.

## 현재 결과

- 이력서 원본: 박성국 페이지 1개
- 공개 프로젝트: 크레인 자동화, ViT 양자화, 시스템 에어컨, PCB 코팅 자동화 4개
- 비공개 학습 초안: 총 47개
  - 상위 학습 페이지 9개
  - 모던 리눅스 하위 페이지 9개
  - C++ 하위 페이지 16개
  - 소프트웨어공학·시스템분석 하위 페이지 61개를 주제별 문서 13개로 통합
- 편집 후 공개한 학습 노트: 5개
  - C++ SOLID 설계 기준
  - C++ STL 컨테이너 선택
  - 모던 C++ 기준선
  - Linux 네트워크 문제 해결
  - Linux 관측가능성 기초 점검
- 프로젝트·학습 노트 양방향 연결: 5개 노트와 3개 프로젝트
- 스터디 플래너 기반 기술 주제 허브: 6개
  - Git & GitHub
  - C++
  - 소프트웨어공학 & 시스템분석설계
  - 모던 리눅스 교과서
  - Android App 개발 with Kotlin
  - Docker & Kubernetes
- 공개 이미지: 프로필·프로젝트 이미지 15개
- 로컬 전용 학습 이미지: 415개, 약 73.3MB

원본 페이지 ID와 대상 파일은 [manifest.json](./manifest.json)에 기록한다.

## 후속 편집

가져온 학습 기록은 로컬 `/drafts/` 경로에서만 검토할 수 있고 배포 빌드에는 포함되지 않는다. 공개용 글은 원본 초안을 보존하면서 별도 Markdown으로 재작성한다. 다음 단계에서는 공개된 5개 노트와 실제 프로젝트 경험을 연결하고, 알고리즘 페이지의 하위 문제 기록은 별도 선별 후 가져오는 편이 적절하다.
